🔍 1. 이진 탐색 (Binary Search) 개념 & 성능

이진 탐색은 **정렬된 배열**에서 탐색 범위를 반씩 줄여가며 데이터를 찾는 알고리즘입니다.

데이터 개수 (N) O(N) 순차 탐색 비교 횟수 O(log N) 이진 탐색 비교 횟수
1,000 개 최대 1,000 번 최대 10 번 ($2^{10} \approx 1024$)
1,000,000 개 (100만) 최대 1,000,000 번 최대 20 번 ($2^{20} \approx 100만$)
10,000,000 개 (1천만) 최대 10,000,000 번 최대 24 번

⚡ 2. 파이썬 bisect 모듈 & 범위 개수 세기

from bisect import bisect_left, bisect_right

arr = [1, 2, 4, 4, 4, 7, 9]

# 1. 숫자 4가 시작하는 첫 인덱스 (2)
left_idx = bisect_left(arr, 4)

# 2. 숫자 4가 끝난 직후 인덱스 (5)
right_idx = bisect_right(arr, 4)

# 3. 특정 범위 [left_val, right_val] 속하는 원소 개수 O(log N)
def count_by_range(a, left_val, right_val):
    return bisect_right(a, right_val) - bisect_left(a, left_val)

📝 4. [실습 문제 6] 나무 자르기 (백준 / LG 빈출)

문제: 나무 목록에서 절단기 높이 H로 잘랐을 때 가져가는 잘린 나무 합이 M 이상이 되도록 하는 절단기 높이 H의 최댓값을 구하세요.

def solution(trees, M):
    left = 0
    right = max(trees)
    result_H = 0
    
    while left <= right:
        mid_H = (left + right) // 2
        
        # mid_H 높이로 자를 때 확보되는 나무 합
        total_wood = sum(tree - mid_H for tree in trees if tree > mid_H)
        
        if total_wood >= M:
            result_H = mid_H  # 정답 후보 저장
            left = mid_H + 1  # 더 높게 잘라볼 수 있는지 오른쪽 탐색
        else:
            right = mid_H - 1 # 나무 부족 ➔ 절단기 낮춤 (왼쪽 탐색)
            
    return result_H
