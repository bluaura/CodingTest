11일차: 다중 시작점 BFS (Multi-source BFS)

시점 0에 모든 출발점을 큐에 동시에 삽입하여 전파 시뮬레이션하는 기법

📌 1. 다중 시작점 BFS 템플릿

from collections import deque

queue = deque()
# 1. 모든 시작점을 큐에 동시에 넣음
for r in range(N):
    for c in range(M):
        if grid[r][c] == 1:
            queue.append((r, c))

# 2. 동시 전파 BFS
while queue:
    r, c = queue.popleft()
    for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
        nr, nc = r + dr, c + dc
        if 0 <= nr < N and 0 <= nc < M and grid[nr][nc] == 0:
            grid[nr][nc] = grid[r][c] + 1
            queue.append((nr, nc))
