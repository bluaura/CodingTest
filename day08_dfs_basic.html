📌 1. DFS (Depth-First Search) 핵심 동작

그래프 탐색 시 **한 노드의 깊은 곳까지 끝까지 내려간 후** 더 이상 방문할 노드가 없으면 되돌아오는(Backtracking) 탐색 방식입니다.

def dfs(graph, node, visited):
    visited[node] = True
    for neighbor in graph[node]:
        if not visited[neighbor]:
            dfs(graph, neighbor, visited)

📝 2. [실습 문제 8] 바이러스 (DFS 백준 2606)

from collections import defaultdict

def solution(n, edges):
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)
        
    visited = [False] * (n + 1)
    
    def dfs(node):
        visited[node] = True
        cnt = 1
        for neighbor in graph[node]:
            if not visited[neighbor]:
                cnt += dfs(neighbor)
        return cnt
        
    return dfs(1) - 1
