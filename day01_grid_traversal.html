🧭 2. 2차원 격자 탐색 (방향 벡터 dr, dc) 원리

📝 3. [실습 문제 1] 상하좌우 로봇 이동 시뮬레이션

문제: N x N 격자의 (0,0)에서 출발하여 명령 문자열('U','D','L','R')에 따라 이동하되, 격자 밖으로 벗어나는 명령은 무시하고 최종 위치를 구하세요.

def solution(N, commands):
    # 현재 위치 (0, 0) 초기화
    r, c = 0, 0
    
    # 딕셔너리를 활용한 가독성 높은 방향 벡터 매핑
    move_dir = {
        'U': (-1, 0),  # 위 (행 -1)
        'D': (1, 0),   # 아래 (행 +1)
        'L': (0, -1),  # 왼쪽 (열 -1)
        'R': (0, 1)    # 오른쪽 (열 +1)
    }
    
    for cmd in commands:
        dr, dc = move_dir[cmd]
        nr = r + dr
        nc = c + dc
        
        # 격자 경계 검사: 범위 안에 있을 때만 위치 갱신
        if 0 <= nr < N and 0 <= nc < N:
            r, c = nr, nc
            
    return r, c

# 테스트 예시
print(solution(5, "RRDDLU"))  # 출력: (1, 1)
