13일차: 서로소 집합 (Union-Find) & MST

find(x) 경로 압축과 union(x,y) 집합 합치기를 통한 그래프 사이클 판별

📌 1. Union-Find 경로 압축 템플릿

parent = list(range(N + 1))

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])  # 경로 압축 (Path Compression)
    return parent[x]

def union(x, y):
    rx, ry = find(x), find(y)
    if rx != ry:
        parent[ry] = rx
        return True
    return False  # 이미 같은 집합 (사이클 감지)
