DAY 05 • 필수 알고리즘 자료구조

5일차: 우선순위 큐 (Heap / Priority Queue) 완벽 정복

O(log N) 시간에 최솟값/최댓값을 유지하는 heapq 모듈의 핵심 테크닉

⛰️ 1. 힙 (Heap) 자료구조 개념 및 시간복잡도

힙(Heap)은 **완전 이진 트리(Complete Binary Tree)** 기반의 자료구조로, 항상 부모 노드가 자식 노드보다 작거나(최소 힙) 크도록(최대 힙) 유지됩니다.

작업 파이썬 heapq 함수 시간 복잡도 비고
요소 추가 heapq.heappush(heap, item) O(log N) 트리 높이만큼만 이동하며 정렬 유지
최솟값 추출 heapq.heappop(heap) O(log N) 루트 노드(최솟값) 제거 후 재정렬
최솟값 확인 heap[0] O(1) 루트 노드는 항상 최솟값
기존 리스트 변환 heapq.heapify(list) O(N) 기존 배열을 in-place로 힙 구조 변환

💡 2. 파이썬 heapq 실전 3대 활용 패턴

1) 최소 힙 (Min Heap) 기본 사용법 
import heapq

heap = []
heapq.heappush(heap, 10)
heapq.heappush(heap, 5)
min_val = heapq.heappop(heap)  # 5 (가장 작은 값 추출)
2) 최대 힙 (Max Heap) - 부호 반전 테크닉

파이썬은 최소 힙만 제공하므로, 넣을 때 마이너스(-val)를 붙여 추출 후 다시 반전시킵니다.

max_heap = []
heapq.heappush(max_heap, -10)
heapq.heappush(max_heap, -20)
max_val = -heapq.heappop(max_heap)  # 20 (가장 큰 값 추출)
3) 다중 조건 튜플 힙 (우선순위, 데이터) 
task_heap = []
heapq.heappush(task_heap, (1, "긴급 작업"))
heapq.heappush(task_heap, (3, "일반 작업"))
priority, task = heapq.heappop(task_heap)  # (1, "긴급 작업")

📝 3. [실습 문제 5] 더 맵게 (프로그래머스 Lv.2 핵심)

문제: 가장 맵지 않은 두 음식을 가장 맵지 않은 스코빌 + (두 번째로 맵지 않은 스코빌 * 2) 공식으로 섞어 모든 음식을 K 이상으로 만드는 최소 횟수를 구하세요.

import heapq

def solution(scoville, K):
    # 1. O(N)으로 리스트를 최소 힙 변환
    heapq.heapify(scoville)
    mix_count = 0
    
    # 2. 최솟값이 K 미만인 동안 반복
    while scoville[0] < K:
        if len(scoville) < 2:
            return -1
            
        first = heapq.heappop(scoville)
        second = heapq.heappop(scoville)
        
        new_scoville = first + (second * 2)
        heapq.heappush(scoville, new_scoville)
        mix_count += 1
        
    return mix_count
