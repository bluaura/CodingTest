DAY 04 • 필수 알고리즘 자료구조

4일차: 해시(Hash Table) & 다중 정렬 패턴

O(1) 탐색 성능의 파이썬 dict/set 과 lambda 기반 람다 정렬

🔑 1. 해시 탐색 (dict & set) vs 리스트 탐색

파이썬의 dict와 set은 내부적으로 **해시 테이블(Hash Table)**을 사용하여 탐색 시간이 평균 $O(1)$입니다.

구문 자료구조 시간 복잡도 특징
item in list 리스트 (List) O(N) 맨 처음부터 끝까지 순차 탐색 (10만 개 탐색 시 시간초과 위험)
item in set 또는 key in dict 집합/딕셔너리 O(1) 해시 함수를 통해 즉시 주소로 접근 (데이터 양과 무관하게 순간 탐색)

🛠️ 2. collections (defaultdict & Counter)

from collections import defaultdict, Counter

# 1) defaultdict: KeyError 예방 및 자동 초기화
scores = defaultdict(int)
scores['classic'] += 500  # 키가 없어도 자동으로 0으로 생성 후 500 더함

song_list = defaultdict(list)
song_list['pop'].append((600, 1))  # 키가 없어도 빈 리스트 [] 생성 후 append

# 2) Counter: 요소의 빈도수 측정
counts = Counter(['apple', 'banana', 'apple'])
print(counts.most_common(1))  # [('apple', 2)] 가장 많이 등장한 요소 추출

📊 3. 다중 조건 정렬 (sort with key=lambda)

여러 정렬 조건(1순위, 2순위, 3순위)이 주어지는 코딩 테스트 문제에서 필수적인 람다(lambda) 정렬 기법입니다.

students = [("Jun", 90, 80), ("Min", 90, 95), ("Kim", 80, 100)]

# 정렬 튜플 (-국어점수, -영어점수, 이름오름차순)
# 숫자 앞에 마이너스(-)를 붙이면 내림차순 정렬이 됩니다!
students.sort(key=lambda x: (-x[1], -x[2], x[0]))

📝 4. [실습 문제 4] 장르별 베스트앨범 고르기

문제: 장르별 총 재생 횟수 기준 내림차순 ➔ 장르 내에서는 재생 횟수 내림차순 ➔ 재생 횟수가 같으면 고유 번호 오름차순으로 최대 2개씩 수집하세요.

from collections import defaultdict

def solution(genres, plays):
    total_plays = defaultdict(int)
    genre_songs = defaultdict(list)
    
    for i, (g, p) in enumerate(zip(genres, plays)):
        total_plays[g] += p
        genre_songs[g].append((p, i))
        
    # 1. 장르별 총 재생 횟수 내림차순 정렬
    sorted_genres = sorted(total_plays.keys(), key=lambda g: total_plays[g], reverse=True)
    result = []
    
    for g in sorted_genres:
        songs = genre_songs[g]
        # 2. 재생 횟수 내림차순(-x[0]), 고유 번호 오름차순(x[1])
        songs.sort(key=lambda x: (-x[0], x[1]))
        
        for p_cnt, song_id in songs[:2]:
            result.append(song_id)
            
    return result
