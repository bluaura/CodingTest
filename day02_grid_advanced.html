💡 회전 좌표 변환 공식 (N x M 행렬 기준)

원래 행렬의 (r, c) 위치에 있던 요소는 90도 시계방향 회전 후 (c, N - 1 - r) 위치로 이동합니다. 

# 90도 시계방향 회전 정석 표준 코드
def rotate_90_clockwise(matrix):
    N = len(matrix)     # 원래 행 개수
    M = len(matrix[0])  # 원래 열 개수
    
    # 회전 후 행렬 크기는 M x N 이 됨
    rotated = [[0] * N for _ in range(M)]
    
    for r in range(N):
        for c in range(M):
            rotated[c][N - 1 - r] = matrix[r][c]
            
    return rotated

🎲 3. 완전 탐색을 위한 itertools (조합 & 순열)

완전 탐색(Brute Force) 문제에서 후보군을 선택할 때 파이썬 내장 라이브러리를 사용하면 손쉽게 조합과 순열을 구할 수 있습니다.

from itertools import combinations, permutations

data = ['A', 'B', 'C', 'D']

# 1) 조합 (combinations): 순서 상관없이 N개 중 K개 선택 (nCk)
comb = list(combinations(data, 2))
# [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'C'), ('B', 'D'), ('C', 'D')]

# 2) 순열 (permutations): 순서를 고려하여 N개 중 K개 선택 (nPk)
perm = list(permutations(data, 2))
# [('A', 'B'), ('A', 'C'), ('A', 'D'), ('B', 'A'), ('B', 'C'), ... ]

📝 4. [실습 문제 2] 지뢰 탐지기 & 90도 회전 시뮬레이션

문제: N x N 지도를 90도 시계방향으로 회전시킨 후, 지뢰가 없는 빈칸(0)에 대해 인접 8방향 지뢰(1)의 개수를 카운트하여 반환하세요.

def solution(N, grid):
    # 1. 2차원 배열 90도 시계방향 회전
    rotated_grid = [[0] * N for _ in range(N)]
    for r in range(N):
        for c in range(N):
            rotated_grid[c][N - 1 - r] = grid[r][c]
            
    # 2. 8방향 벡터 정의
    dr = [-1, 1, 0, 0, -1, -1, 1, 1]
    dc = [0, 0, -1, 1, -1, 1, -1, 1]
    
    result_grid = [[0] * N for _ in range(N)]
    
    for r in range(N):
        for c in range(N):
            if rotated_grid[r][c] == 1:
                result_grid[r][c] = -1  # 지뢰 위치 표기
            else:
                mine_count = 0
                for i in range(8):
                    nr, nc = r + dr[i], c + dc[i]
                    if 0 <= nr < N and 0 <= nc < N:
                        if rotated_grid[nr][nc] == 1:
                            mine_count += 1
                result_grid[r][c] = mine_count
                
    return result_grid
