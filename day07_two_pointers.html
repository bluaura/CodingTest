7일차: 투 포인터, 슬라이딩 윈도우 & 1주차 마스터

O(N^2) 이중 반복문을 O(N)으로 단축시키는 투 포인터 테크닉과 1주차 핵심 가이드

👉 1. 투 포인터 (Two Pointers) 핵심 원리

1차원 배열에서 **두 개의 포인터(인덱스)** 위치를 조건에 따라 조작하며 $O(N)$ 시간에 문제를 해결하는 기법입니다.

동일 방향 투 포인터 (start, end) 동작 알고리즘
    current_sum < k 이면: end += 1 (합을 키우기 위해 오른쪽으로 확장) current_sum >= k 이면: start += 1 (합을 줄이거나 다음 구간을 위해 왼쪽을 축소)

🏆 2. 1주차 데이터 구조 & 알고리즘 선택 요약 가이드

일차 알고리즘 / 자료구조 대표 활용 상황 시간 복잡도
1일차 2차원 격자 탐색 (dr, dc) 상하좌우 미로/지도 이동, 방향 시뮬레이션 $O(N \times M)$
2일차 배열 회전 & itertools 90도 행렬 회전, 완전탐색 조합/순열 $O(N^2)$, $O(_nC_k)$
3일차 스택 & 덱 (deque) 괄호 짝 맞추기, 프로세스 큐 회전시뮬레이션 $O(1)$ (popleft)
4일차 해시(dict/set) & 람다정렬 빠른 요소 존재 검사, 장르/다중 조건 정렬 $O(1)$ 탐색
5일차 우선순위 큐 (heapq) 최솟값/최댓값 실시간 유지 및 믹싱 $O(\log N)$
6일차 이진탐색 & 매개변수탐색 정렬된 배열 빠른 탐색, 조건 만족 최댓값 $H$ $O(\log N)$
7일차 투 포인터 & 슬라이딩 윈도우 연속 부분 수열 합, 두 수의 합, 구간 최댓값 $O(N)$

📝 3. [실습 문제 7] 연속된 부분 수열의 합 (프로그래머스 Lv.2)

문제: 정렬된 수열에서 연속 부분 수열의 합이 k인 구간 중 가장 짧고, 시작 인덱스가 빠른 구간 [left, right]를 구하세요.

def solution(sequence, k):
    n = len(sequence)
    left, right = 0, 0
    current_sum = sequence[0]
    
    min_len = float('inf')
    result = [0, 0]
    
    while left <= right and right < n:
        if current_sum == k:
            current_len = right - left + 1
            if current_len < min_len:
                min_len = current_len
                result = [left, right]
            current_sum -= sequence[left]
            left += 1
        elif current_sum < k:
            right += 1
            if right < n:
                current_sum += sequence[right]
        else:
            current_sum -= sequence[left]
            left += 1
            
    return result
